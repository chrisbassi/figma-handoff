O componente Card à esquerda e o código à direita saem do __NAME__, a partir de um arquivo Figma de exemplo. Nada nesta área foi escrito à mão.

Como funciona

  1. 1

    Carregue o arquivo

    Cole a URL do arquivo e o seu token pessoal do Figma. A ferramenta lê o arquivo inteiro, então não precisa publicar biblioteca nenhuma.

  2. 2

    Confira a prévia

    Cada componente aparece renderizado antes de qualquer arquivo ser gerado, com a lista do que não foi convertido. Marque só os que você quer.

  3. 3

    Gere o código

    Escolha HTML, Blade ou React. Sai um CSS por componente, mais um preview.html com todos. Grave na pasta do projeto ou baixe um ZIP.

O que sai do arquivo de design

Auto-layout vira flexbox: direção, espaçamento, padding, alinhamento e quebra de linha. Camadas fora de auto-layout ficam em posição absoluta.

Cores, tipografia e sombras que vêm de estilos do Figma viram variáveis CSS com o valor literal de reserva, então o componente funciona até sem o arquivo de tokens.

Os nomes das camadas viram classes no padrão BEM, como .ds-card__title. Camadas chamadas "Frame 12" geram classes chamadas frame-12, então vale nomear direito no Figma.

Instalar e rodar

Precisa de Node.js 20 ou superior e de um token pessoal do Figma com permissão de leitura de arquivos (em Settings, Security, Personal access tokens).

# clonar e abrir a interface em http://127.0.0.1:4173
git clone https://github.com/__REPO_SLUG__.git
cd __NAME__
npm install
npm run ui
npm run ui
Abre a interface: lista os componentes com prévia e gera o código.
node dist/cli.js components
Gera os componentes pela linha de comando, sem a interface.
node dist/cli.js sync
Gera o tokens.css a partir dos estilos publicados do arquivo.
node dist/cli.js diff
Mostra o que mudou no Figma desde o último sync.

O que ainda não faz

  • Ícones e vetores viram um espaço reservado do tamanho certo, com aviso. Exportar SVG é o próximo passo.
  • O texto sai fixo, igual ao do design, sem props. Instâncias e overrides não são interpretados.
  • Os tokens dependem de estilos publicados na biblioteca do arquivo, e publicar é recurso de plano pago do Figma. Os componentes não dependem disso.
  • Layout sem auto-layout reproduz o design em posição absoluta, então não é responsivo.
